# FAIR-Data-Engineering-2025-Group15-FIFA-Rankings

This repository contains the FAIRified version of the **FIFA Men’s International Soccer Rankings (1993–2025)** dataset, created as part of the **FAIR Data Engineering 2025** course at the **University of Twente**.

The project follows the FAIRification process, including data cleaning, ontology modeling, RDF transformation, and metadata publication.


## Folder Descriptions

- **data/** — Contains both the original CSV dataset and the FAIRified RDF (Turtle) version.  
- **ontology/** — Defines the semantic model (classes and properties) used to describe teams, confederations, and ranking records.  
- **metadata/** — Contains RDF metadata describing the dataset and its two distributions (original and FAIRified).  
- **metadata_schema/** — Contains SHACL schemas defining the structure and constraints for dataset and distribution metadata.  
- **README.md** — Provides a description of the repository and its structure.
